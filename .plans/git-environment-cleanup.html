03 Recorded Cleanup

The proposed operation was a reversible metadata pass with no source or history changes.

The plan called for a fresh dry-run immediately before cleanup, pruning deleted remote-tracking refs, asking Git to discover and record GitHub's default branch, and enabling per-repository pruning on future fetches. It then verified that main remained clean and synchronized and that release tags remained present.

Non-goals
  • Do not delete GitHub branches: GitHub already has only main.
  • Do not delete release tags, rewrite commits, reset main, clean build products, or remove reflogs.
